# Кластеризация и многоклассовая классификация на датасете 20Newsgroups

## Результаты

- **Лучшая модель:** LogisticRegression + TF‑IDF (F1-macro = 0.907)
- **Бинарная классификация space/religion:** F1 = 0.96
- **Кластеризация:** KMeans, ARI = 0.26
